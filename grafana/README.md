# grafana

Grafana OSS, provisioned entirely from this folder: datasources, dashboards, and alert
rules. Nothing is configured by hand. UI: <http://localhost:3060> (admin password is in
your `.env`, generated by `make env`).

| Dashboard | What it answers | Refresh |
| --- | --- | --- |
| Live Network Overview (home) | How is the network right now, and how did we get here? Live numbers, station map at any moment (rewind with the time picker), 5-minute history. | 10 s |
| Station Drilldown | What is happening at one station? | 30 s |
| Rebalancing Board | Where should trucks go next? Ranked list, map, need by borough. | 10 s |
| Daily Review | How did availability change over days, by borough, hour, and weather? | 5 min |
| Dockline Live (public) | Embeddable live view for the website (shared publicly; no variables). | 10 s |

Every metric comes from Cube's SQL API ([ADR 0014](../docs/adr/0014-grafana-reads-metrics-through-cube.md)).
Imbalance states always use the Dockline colors **and** a label: starving (orange
`#E0701F`), balanced (gray `#A9B3C1`), flooding (blue `#2357C6`), offline (purple
`#7A6F9B`).

## Dashboards are code

Edit `build_dashboards.py`, then:

```bash
make grafana-dashboards
```
```bash
make check-grafana
```

`check-grafana` sends every panel query through Grafana and checks the datasources and
alert rules. A unit test fails if the committed JSON does not match the builder.

```bash
make grafana-public
```

prints the public dashboard URL (creating the share if needed).

## Alerts (`provisioning/alerting/rules.yml`)

Firing alerts show in Alerting and as annotations; pipeline events from Dagster
(`ops.pipeline_events`) are annotated on every dashboard. Contact points (email, chat)
are added at deployment (Phase 7).

### Feed stale
`data_freshness_seconds > 300` for 1 minute (no data also fires). Check
`docker compose ps ingestion` and `docker compose logs ingestion`; confirm the GBFS feed
is reachable. `make test-stale-alert` stops ingestion until this fires, then restarts it.

### High-traffic station empty
A station in the busiest 10% at this hour of day has had no bikes for more than 10
minutes. One alert per station (label `station`). Put it on the next truck route via the
Rebalancing Board.

### Ingestion runs failing
At least one run in `ops.ingestion_runs` failed (after retries) in the last 10 minutes.
`SELECT feed, error_message FROM ops.ingestion_runs WHERE status = 'failed' ORDER BY run_id DESC LIMIT 5;`
